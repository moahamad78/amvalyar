# محدودهٔ دسترسی نقش‌ها

محدودهٔ داده جدا از مجوز انجام عملیات کنترل می‌شود. داشتن مجوز مشاهده، مجوز ویرایش یا مشاهدهٔ قیمت را ایجاد نمی‌کند.

| نقش | محدودهٔ دارایی | اطلاعات مالی پیش‌فرض |
| --- | --- | --- |
| مدیر کل سامانه | همهٔ شرکت‌ها | دارد |
| مدیر سامانهٔ شرکت | شرکت خودش | دارد |
| مدیر مالی، رئیس حسابداری، مدیرعامل | شرکت خودش | دارد |
| سرجمع‌دار، مدیر اموال، مدیر/سرپرست انبار، بازرسی | شرکت خودش | ندارد |
| مدیر واحد و رؤسای فنی، تولید، برنامه‌ریزی، اداری، بازرگانی، منابع انسانی و سیستم‌ها | واحدهای مرتبط با پروفایل پرسنلی خودش و اموال خودش | ندارد |
| پرسنل و نقش فاقد مجوز گسترده | اموال خودش | ندارد |

مجوزهای مستقل `assets.view_all` و `assets.financial` برای نقش‌های سفارشی قابل تخصیص هستند. نقش استاندارد پرسنل، حتی با تخصیص اشتباه مجوز، به عملیات شخصی محدود است. مجوز ثبت یا ویرایش به‌تنهایی باعث مشاهدهٔ کل شرکت نمی‌شود؛ برای نقش سفارشی، گسترش محدوده فقط با `assets.view_all` انجام می‌شود.

پروفایل پرسنلی بدون واحد باعث دسترسی به تمام واحدها نمی‌شود. اموال شخص هم با `custody_user_id` و هم پروفایل‌های `custody_employee_id` مرتبط با همان کاربر تشخیص داده می‌شود.

داشبورد پرسنل اطلاعات ظرفیت اشتراک، کاربران، ارزش شرکت یا آخرین گردش‌های عمومی را بارگیری نمی‌کند. مدیر واحد داشبورد محدود به حوزهٔ خودش دارد. قیمت‌ها در گزارش عددی، اکسل و نمودار ارزش کنترل می‌شوند؛ فیلتر قیمت برای کاربران غیرمالی پذیرفته نمی‌شود.

اعتبارسنجی: `tools/run-tests-isolated.ps1 --filter=RoleVisibilityTest`. اجرای مجموعهٔ قدیمی نیازمند fixtureهایی مانند `testadmin` و شرکت شمارهٔ ۲ است.
